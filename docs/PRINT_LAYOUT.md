# 印刷用PDFの統一レイアウト

2026-10-10と2026-10-17のPDFは、承認された過去3回の印刷様式に合わせた `reference-v1` で生成します。対象日は `assets/print-layouts.json` で管理し、それ以外の日付は従来の処理を使います。

- 青い表紙、開始ページ番号付き目次、教科別の配色と枠付き本文。
- 国語・英語・社会・数学の要点・数学の実践・理科の6種類を収録。
- 各教材は奇数ページから開始し、必要な偶数ページは両面印刷の調整ページにする。
- 本文は `content/YYYY-MM-DD` の同じ確認済みHTMLを使用し、確認問題の解答を展開する。
- PDFを生成してからZIPへ収録するため、単独PDFとZIP内PDFは同じ内容になる。

GitHub Actionsは `requirements-print.txt` をインストールし、`scripts/render-pdf.cjs` から統一版を自動生成します。日本語フォントは公式Noto Sans JPを取得し、SHA-256を確認します。フォント取得・検証が失敗した場合は公開を停止します。

ローカルでは `python3 -m pip install -r requirements-print.txt` を実行します。別のPythonを使う場合は `PRINT_PYTHON`、取得済みの同一フォントを使う場合は `PRINT_REFERENCE_FONT` に絶対パスを設定できます。出力先は従来どおり新しいビルド先を指定してください。

新しい回も同じ様式にする場合は、内容確認後に対象日を設定へ追加し、目次・奇数ページ開始・数式・表の分断・PDFとZIPの一致を確認します。既存の日付を変更する際はプロジェクトの上書き確認ルールに従います。
