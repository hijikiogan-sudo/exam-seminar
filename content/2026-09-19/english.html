この回の要点

この回は、名詞の数・数え方と文型（とくにSVOC）を結びつけて、見た目にだまされず英文の構造を取る練習です。

可算・不可算
「個体」か「物質・食材」かで冠詞や複数形が変わる。
単複同形
fish / deer / sheep などは複数でも形が変わらないことがある。
every + 単数
every の後ろは原則として単数名詞。動詞も単数扱い。
SVOC
OとCの間に「O＝C」「OがCの状態」の関係がある。

講義内容を順に整理

1. fish のような「形だけでは単数・複数が決まらない名詞」

fishdeersheepは、文脈によって複数でも同じ形を取ることがあります。したがって、名詞だけで判断せず、some / many / 数詞 / 動詞など周辺情報を見ることが重要です。

例： some fish の fish は、形が fish のままでも複数を表せます。入試では「複数形＝必ず -s」と思い込ませる選択肢に注意します。

2. 同じ名詞でも「動物」と「食材」で数え方が変わる

意味考え方例
1羽のニワトリ個体として数えるa chicken
鶏肉食材・物質として扱うchicken
魚（個体）文脈により単数・複数a fish / some fish
魚肉・魚料理食材として不可算的に扱うことがあるfish

講義では fish や chicken を使い、名詞の意味によって数え方が変わる点が強調されていました。

3. every の後ろは単数名詞

every + 単数名詞 ＋ 単数扱いの動詞

every は「一つ一つを全部」という見方をするため、後ろの名詞を単数形にします。主語が every student のような形なら、現在形の動詞は原則三単現になります。

4. pair で数える名詞

pants のように通常複数形で扱う名詞は、個数を示すとき a pair of pants、2組なら two pairs of pants のように表します。

5. SVOC：leave O C

Don’t leave the door open.
S省略 / V leave / O the door / C open

この文では the door = open の状態という関係があります。C（補語）はOの状態・性質を説明します。

なぜそうなるか

名詞は「形」ではなく「意味＋文脈」で判断する

英語の名詞は、日本語のように数の情報を省略しにくいため、冠詞・複数形・数量表現に数の情報が現れます。一方、fish のような単複同形語や chicken のように意味で可算性が変わる語があるため、名詞単体だけを見ると誤るのです。

文型は訳す前に「役割」を決める

SVOCを先に取ると、open を「開ける」と動詞のように誤読せず、「door の状態を説明する補語」と判断できます。長文でもこの習慣が構造把握を速くします。

入試での問われ方

頻出パターン
  • 名詞の単数・複数、冠詞 a/an の有無。
  • some / many / every など数量語との組み合わせ。
  • 同じ語でも意味の違いによる可算・不可算の判別。
  • 語句整序で leave + O + C を組ませる。
  • 下線部の文型判定、OとCの意味関係の説明。

解き方の順序

  1. 名詞の前に数量語・冠詞があるか。
  2. その名詞は「個体」か「物質・食材」か。
  3. 主語の単複と動詞の形が一致しているか。
  4. 動詞の後ろに「O＝C」の関係が作れるか。
  5. 最後に自然な日本語へ訳す。

つまずきやすい点

複数なら必ず -s
fish / deer / sheep などの単複同形に注意。
chicken は常に同じ数え方
個体と食材で扱いが変わる。
every の後ろを複数形にする
every + 単数名詞が基本。
open をVと誤認
leave O C の CとしてOの状態を説明している。

確認問題

Q1. “every students” のどこが問題？

every の直後は原則単数名詞なので、every student とします。

Q2. “two ___ of pants” の空欄は？

pairs。2組なので two pairs of pants です。

Q3. “Keep the room clean.” で O と C は？

O = the room、C = clean。room が clean な状態、という関係です。

Q4. “chicken” が無冠詞で使われやすいのはどんな意味？

鶏肉・食材として物質的に扱うときです。
