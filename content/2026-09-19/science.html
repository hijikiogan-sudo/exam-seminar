この回の要点

テーマはイオン・電離・化学式・電気分解・中和計算。個別暗記ではなく、イオンの電荷を覚える → 電荷が打ち消し合う比で化学式を作る → 電離式・反応式・計算へ広げる流れです。

基礎

電離

多原子イオン（NH4+、OH−、NO3−、SO42−、CO32−など）は、ひとかたまりとして扱います。

2. 電離式：係数と電荷を混同しない

NaOH → Na+ + OH−
Ba(OH)2 → Ba2+ + 2OH−
H2SO4 → 2H+ + SO42−
CuSO4 → Cu2+ + SO42−
CuCl2 → Cu2+ + 2Cl−
NH4Cl → NH4+ + Cl−

左辺と右辺で原子の個数と電荷の合計が一致するか確認します。右上の2+は「2個」という意味ではありません。

3. イオンの電荷から化学式を作る

物質組み合わせ化学式
酸化銅Cu2+ と O2− → 1:1CuO
酸化銀Ag+ 2個 と O2− 1個Ag2O
硫酸バリウムBa2+ と SO42− → 1:1BaSO4
炭酸カルシウムCa2+ と CO32− → 1:1CaCO3

講義では、イオン式を暗記しておくと化学式の個数比が判断できることが強調されていました。BaSO4 と CaCO3 は白色沈殿としても頻出です。

4. 電気分解：塩化銅水溶液

電離は CuCl2 → Cu2+ + 2Cl−。銅イオンを含む水溶液は青色で、陰極側には赤色〜赤褐色の銅が析出します。陽極側では塩素が発生します。

銅
Cu2+：青色の水溶液
Cu：赤色〜赤褐色の固体
塩素
黄緑色・刺激臭・漂白作用。空気より重い気体。

5. 中和計算は「中和する体積比」を保存する

ある濃度の酸とアルカリが完全に中和する組合せがわかれば、その濃度が同じ限り、必要量は比例します。

15 cm³ : 21 cm³ = 2.0 cm³ : x cm³
→ x = 2.8 cm³

別の例では、HCl 10 cm³ と NaOH 12 cm³ が中和する条件を使い、残ったNaOH 8 cm³に対応するHCl量を比例式で求めると、約6.7 cm³になります。

なぜそうなるか

化学式は「全体の電荷が0」になるように決まる

イオン結晶全体は電気的に中性なので、陽電荷と陰電荷が打ち消し合う最小の整数比で組み合わせます。

電離式では「個数」と「電荷」を別に見る

2Cl− の左の2は塩化物イオンが2個あること、右上の−は各イオンが−1の電荷を持つことを表します。

中和計算が比例になる理由

濃度が固定なら、体積に比例してH+やOH−の量も増えます。したがって「完全中和する体積比」がそのまま必要量の比として使えます。

入試での問われ方

頻出パターン
  • イオン名 ↔ イオン式の対応。
  • 電離式の係数・電荷・原子数の穴埋め。
  • 電荷から化合物の化学式を決める。
  • 塩化銅水溶液の電気分解で、電極の生成物と色・性質を問う。
  • 中和点をグラフや体積比から求める。
  • 沈殿の色や生成物を選ぶ。

解答チェック3点セット

  1. 原子数が左右で合っているか。
  2. 電荷の合計が左右で合っているか。
  3. 係数を最小の整数比にできているか。

つまずきやすい点

2+を「2個」と読む
右上は電荷。個数は式の前の係数や右下の添字で表す。
多原子イオンを分解する
SO₄²⁻、OH⁻などはひとかたまりとして扱う。
中和で「加えた側」を逆にする
どちらにどちらを加えたか、最初に図示する。
塩素の性質を混同
黄緑色・刺激臭・漂白作用をセットで整理する。

確認問題

Q1. Ba(OH)₂ の電離式を書け。

Ba(OH)2 → Ba2+ + 2OH−

Q2. Al³⁺ と O²⁻ からできる化合物の最簡化学式は？

電荷の最小公倍数は6なので、Alを2個、Oを3個。Al₂O₃です。

Q3. CuCl₂水溶液の陰極に現れる物質と色は？

銅。赤色〜赤褐色の固体として析出します。

Q4. HCl 10 cm³ と NaOH 12 cm³ が完全中和する。同じ濃度条件でNaOH 6 cm³に必要なHClは？

10:12 = x:6 より x=5 cm³。
