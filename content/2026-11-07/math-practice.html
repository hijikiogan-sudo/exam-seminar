① 平行四辺形の一部分は、全体の何倍か

再構成問題｜動画 02:24〜02:29

問題：平行四辺形ABCDで、Eは辺CD上、CE：ED=1：2。AEとBDの交点をFとします。△DFEは平行四辺形ABCDの何倍ですか。

着眼点

AB∥DE、A・F・E、B・F・Dがそれぞれ一直線上なので、砂時計型の△BAFと△DEFが相似です。AB=CDより、DE：AB=2：3。

途中式

  1. △DFE：△BAFの相似比は2：3。面積比は4：9。△DFEを4、△BAFを9と置く。
  2. 相似からEF：FA=2：3。△DFEと△DFAは、底辺をEF・FAに取ればDからの高さが同じ。面積も2：3なので、△DFAは6。
  3. △ABDは△BAFと△AFDを合わせたものだから、9+6=15。
  4. BDは平行四辺形を等しい面積の2つに分けるので、全体は15×2=30。
△DFE ÷ 平行四辺形ABCD = 4/30 = 2/15

解答・吟味

2/15倍。一部分を全体で割るので1より小さくなります。4・9・6・30は同じ面積比の単位でそろっています。

失点ポイント：相似比2：3を、そのまま面積比にしないこと。全体は△ABDの2倍であり、9+4だけを全体にしないこと。

② 合同な三角形へ置き換える

再構成問題｜動画 02:29〜02:42

条件：△ABCで、DはBC上、BD：DC=1：2。EはADの中点、FはACの中点です。Fを通りADに平行な直線とDCの交点をG、直線BEとACの交点をHとします。①△BDE≅△DGFを示し、②BE：EH、③△ABC：△DGFを求めます。

① 合同の根拠

  1. △CADでFはCAの中点、FG∥ADなので、GはCDの中点。したがってDG=DC/2=BD。
  2. 同じ相似からGF=AD/2=DE。
  3. DBとGDは同じ直線BC上で同じ向き、DE∥GFなので、∠BDE=∠DGF。
  4. 2組の辺とその間の角がそれぞれ等しく、△BDE≅△DGF。

② BE：EH

合同の対応からBE=DF、∠DBE=∠GDF。したがってBE（BH）∥DF。△ADFでEがADの中点だから、中点連結の関係によりEH=DF/2。

BE = DF = 2EH → BE：EH = 2：1

③ 面積比

合同なので、△DGFを△BDEに置き換えます。EがADの中点なので、Bからの高さを共通に取ると、△ABE：△BDE=1：1。△ABD：△ADC=BD：DC=1：2です。

△BDEを1 → △ABEも1 → △ABDは2
△ADCは4 → △ABCは6
△ABC：△DGF = 6：1

別解・吟味

補足の別の見方として、△FGCと△ADCの相似比は1：2。GはDCの中点なので△DGFと△FGCは等積です。したがって△DGFは△ADCの1/4で、△ADCは△ABCの2/3。積を取れば(1/4)×(2/3)=1/6になります。

失点ポイント：相似の対応、合同の対応を混同しないこと。「合同だから面積が等しい」を使うと、複雑な図から必要な三角形だけへ移せます。

③ 平行四辺形を見つけ、面積を足す

再構成問題｜動画 02:43〜02:50

条件：平行四辺形ABCDで、EはBC上、BE：EC=5：2。FはAD上でAE∥FCとなるように取り、GはACとFEの交点、HはAEとDCをそれぞれ延長した交点とします。四角形CGEHと平行四辺形ABCDの面積比を求めます。

着眼点

講義では、等しい錯角からAE∥FCを見つけました。AF∥CEもあるので、AFCEは平行四辺形。Gはその対角線ACとFEの交点です。

途中式

  1. AB∥HC、B・E・C、A・E・Hが一直線上なので、△ABEと△HCEは相似。相似比5：2から面積比25：4。
  2. △ABEと△AECは底辺BE・ECが5：2で高さが共通。△ABEを25とすると、△AECは10。
  3. AFCEの対角線ACとFEは互いに中点で交わるので、GはAEではなくACとFEの中点。FEは△AECを等しい面積の2つに分け、△CGE=5。
  4. 四角形CGEH=△CGE+△CEH=5+4=9。
  5. △ABC=△ABE+△AEC=25+10=35。平行四辺形ABCDはその2倍で70。
四角形CGEH：平行四辺形ABCD = 9：70

解答・吟味

9：70。求める四角形のうち、△CEHは平行四辺形の外側にあります。形の印象で範囲を変えず、頂点C→G→E→Hの順に囲って確かめます。

失点ポイント：「25と4」だけで終わらず、△CGEの5を足します。小さい平行四辺形AFCEを見つけることが、10を半分の5に分ける根拠です。

⑤ 共通の三角形を基準にそろえる

再構成問題｜動画 02:50〜02:55

条件：AB=AC=12cm、BC=8cmの二等辺三角形ABCで、DはAB上、EはAC上、DE∥BC、DE=2cm。BFは∠ABCの二等分線で、FはAC上です。△FBCは△ADEの何倍かを求めます。

着眼点・途中式

  1. △ADE∽△ABC。相似比2：8=1：4なので、△ADE：△ABC=1：16。
  2. 角の二等分線の定理よりAF：FC=AB：BC=12：8=3：2。
  3. △ABFと△FBCは、底辺AF・FCを取るとBからの高さが共通。したがって△FBCは△ABCの2/5。
  4. 共通の△ABCを80とそろえると、△ADEは5、△FBCは32。
△FBC ÷ △ADE = (2/5)÷(1/16) = 32/5

解答・吟味

32/5倍。△ADEの方が小さいので、倍率が1より大きくなることを確かめます。面積比なら△FBC：△ADE=32：5、逆向きなら5：32です。

検算の補足：△ABCの高さは√(12²−4²)=8√2 cm、面積は32√2 cm²。△ADEは2√2 cm²、△FBCは64√2/5 cm²となり、割ると32/5です。比だけで解いた方が短いですが、実際の面積に戻しても一致します。

失点ポイント：1：16と2：5は基準の大きさが違います。「1と2だけ」を比べず、共通の△ABCをそろえてから比べます。

類題・確認問題

まず答えを見ずに解き、答えだけでなく理由も確かめましょう。確認問題は講義内容を練習するために、このガイドで作成しました。

問1　【①の類題】CE：ED=1：1の場合、△DFEは平行四辺形ABCDの何倍か。その他の点の取り方は①と同じ。

相似比△DFE：△BAF=1：2、面積比1：4。△DFEを1とすると、△ADFは2、△ABDは4+2=6、全体は12。よって1/12倍です。

問2　【②の類題】同じ条件で△ABCの面積が72cm²なら、△DGFは何cm²か。
72÷6 = 12cm²

△ABC：△DGF=6：1を使います。

問3　【③の類題】BE：EC=2：1に変える。他の条件は③と同じとき、四角形CGEH：平行四辺形ABCDを求めよう。

△ABE：△ECH=4：1。△AECは、△ABEとの底辺比から2。△CGEはその半分で1。四角形CGEHは1+1=2、全体は2×(4+2)=12。よって1：6です。

問4　【⑤の類題】DEだけを4cmに変える。△FBCは△ADEの何倍か。AB=AC=12cm、BC=8cm、BFは角の二等分線。

△ADEは△ABCの(4/8)²=1/4。△FBCは変わらず△ABCの2/5なので、(2/5)÷(1/4)=8/5倍です。

解き直しの手順

  1. ①：相似比2：3から、面積の4・9・6・30を順に再現する。
  2. ②：合同の証明を読み、BE：EH=2：1と面積比6：1を別々に説明する。
  3. ③：AFCEを囲み、面積25・10・5・4がどこに入るか指す。
  4. ⑤：全体を80にそろえる理由を説明し、DE=4cmの類題へ進む。
