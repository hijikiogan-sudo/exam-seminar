要点

動画 03:06〜03:43ごろ　ウイニングフィニッシュ158〜161ページのエネルギー、221ページの浮力、220ページの電磁誘導を復習しました。

到達点：エネルギーの変換効率と単位を確かめ、浮力を体積・つり合いから求め、電磁誘導を磁界の変化で説明します。

講義整理：エネルギーの移り変わり

装置・現象もとのエネルギー → 主な変換先
電気ストーブ・アイロン電気 → 熱
石油・ガスストーブ燃料の化学 → 熱
ホタルの発光化学 → 光
モーターでおもりを上げる電気 → 位置エネルギーなど
摩擦による火起こし運動 → 熱
ばね・ゴムを変形する弾性エネルギーを蓄える

位置エネルギーと運動エネルギーの和が力学的エネルギーです。摩擦などで熱や音へ移れば、力学的エネルギーは減ることがありますが、それらを含む全体のエネルギーが消えるわけではありません。

力学的エネルギーの保存を使うには、摩擦・空気抵抗による損失や、モーターなどからの外部の仕事がないかを確認します。「エネルギー保存の法則」と、条件のある「力学的エネルギー保存の法則」を分けましょう。

なぜそうなるか：式と単位

求める量式時間などの単位
仕事[J]力[N]×その力の方向の距離[m]cmはmに直す
電力[W]電圧[V]×電流[A]電力と電力量を区別
電力量[J]電力[W]×時間[s]秒を使う
電力量[Wh]電力[W]×時間[h]時間を使う
水が受け取る熱量[J]4.2×水の質量[g]×上昇温度[℃]水の比熱を4.2として計算
変換効率[％] = 目的に使われたエネルギー ÷ もとのエネルギー ×100

講義の整理｜動画 03:11〜03:12

モーターの変換効率

200gのおもりを0.8m上げる。100gに働く重力を1Nとし、電源は1.0V・0.4Aで10秒使います。

仕事 = 2N×0.8m = 1.6J
電力量 = 1.0V×0.4A×10s = 4.0J
効率 = 1.6÷4.0×100 = 40％

講義の整理｜動画 03:16〜03:20

LED電球と、J・Whの違い

6WのLED電球を5分使用し、450Jが光に変わる例。

もとの電気エネルギー = 6×300 = 1800J
光への効率 = 450÷1800×100 = 25％

別の比較問題は、60Wの白熱電球と7.5WのLED電球でした。

白熱電球：60W×2h = 120Wh
電流：60W÷100V = 0.6A
同じ120Whを使うLEDの時間：120÷7.5 = 16h
Jなら秒、Whなら時間。40分は40/60時間であって、40時間ではありません。LEDも発熱がゼロではなく、熱として出る割合が少ないことを、光に変える効率と結び付けます。

熱の伝わり方を説明する

動画 03:12〜03:16。選択肢の記号だけでなく、現象の違いを説明する練習をします。

伝わり方内容復習用の例
伝導物質全体が移動しなくても、熱が内部を伝わる金属の一端を温めると、離れた部分も温まる。
対流温められた気体・液体が移動し、熱を運ぶ温められた水が上昇し、全体が温まる。
放射電磁波によって、空間を隔てて熱が伝わる太陽や熱源から、離れた所へエネルギーが伝わる。
放射は「反射」と同じではありません。熱源と受け取る物体の間に、熱を運ぶ物質の移動が必要なわけでもありません。

入試での問われ方：浮力

動画 03:21〜03:35。外形の体積が同じで、重力だけが異なる容器P・Qを比べました。水が入ったり形が変わったりせず、容器は底に接しない条件です。

状態つり合い・計算浮力など
P：重力0.30N、水に浮いて静止上向きの浮力＝重力浮力0.30N
Q：空気中5.00N、水中のばねばかり4.50N浮力＝空気中の値−水中の値浮力0.50N
P・Qが全部水中同じ水中の体積なら浮力も同じどちらも浮力0.50N
Pを糸で下から引き、全部水中で静止浮力＝重力＋糸の力糸の力0.20N、下向き

Pは高さ5cmで、3cm分が水中にあるとき浮力0.30N。底面積が一定なので、全部沈むと0.50Nと考えられます。全部沈んだ後は、水中の体積が変わらないため、さらに深くしても浮力は変わりません。

力の作図

1目盛り0.1Nなら、Pの重力は下向き3目盛り、全部沈めて静止させる糸の力は下向き2目盛り。重力は物体の中心から、糸の力は糸が物体に付く場所から描くという、作用点の違いも確認します。

浮力は、同じ液体では主に水中に沈んだ部分の体積で比べます。「質量が小さいほど浮力が大きい」「沈む物体には浮力がない」は誤りです。沈むときにも浮力は働きます。

入試での問われ方：電磁誘導

動画 03:36〜03:43。220ページの問題を短時間で解き、最後に電磁誘導とワイヤレス充電の原理を確認しました。

中心：コイルを貫く磁界が変化すると誘導電流が流れる。磁石を置いたままにしただけでは、電流が流れ続けるわけではありません。
磁石に向かい合う面で見るコイル側にできる極
N極が近づくN極（近づく変化を妨げる）
N極が遠ざかるS極（離れる変化を妨げる）
S極が近づくS極
S極が遠ざかるN極

検流計の左右の振れは配線によって変わるので、元の実験図と合わせて確認します。「N極が近づくといつも左」と固定して覚えないようにします。

講義の整理｜動画 03:42〜03:43

スイッチを入れた瞬間だけ、なぜ振れるか

  1. 電源につないだコイルに電流が流れ始めると、周囲の磁界が変化する。
  2. もう一方のコイルに、その変化による誘導電流が生じる。
  3. 直流が一定になり磁界が変化しなくなると、誘導電流は0に戻る。
  4. 交流は電流と磁界が時間とともに変わるので、誘導を継続させるしくみに使える。

講義では、この考え方をワイヤレス充電のしくみと結び付けました。

注意点

取り違え直し方
電力量180Jで450Jの光が出ると計算する6W×5分は1800J。効率が100％を超えたら単位・桁を点検。
エネルギーが熱になったら消えたとする目的以外のエネルギーへ移った。総量と区別。
浮いているPと、全部沈めたPの浮力を同じにする水中の体積が違う。浮いているときは重力とつり合う。
水圧と浮力は、深いほど両方増えるとする全部沈んだ同じ体積なら、浮力は一定。
電磁誘導は、磁石が近くにあるだけで続くとする必要なのは磁界の変化。

確認問題

まず答えを見ずに解き、答えだけでなく理由も確かめましょう。確認問題は講義内容を練習するために、このガイドで作成しました。

問1　石油ストーブと電気ストーブで、もとのエネルギーは何が違うか。

石油ストーブは燃料の化学エネルギー、電気ストーブは電気エネルギーを熱に変えます。

問2　摩擦で運動エネルギーが熱に変わったとき、エネルギーは消えたか。

消えていません。熱なども含むエネルギーの総量は保存されます。力学的エネルギーだけが保存される場合と区別します。

問3　モーターに4.0Jを与え、おもりを上げる仕事が1.6Jだった。変換効率は？
1.6÷4.0×100 = 40％

目的のエネルギーを、もとのエネルギーで割ります。

問4　6WのLED電球を5分使い、450Jが光に変わった。使った電気エネルギーと効率は？
6×(5×60)=1800J
450÷1800×100=25％
問5　物質が移動する・移動しない・空間を隔てる、の順に熱の伝わり方を答えよう。

対流・伝導・放射。対流は気体・液体の移動で熱が運ばれる現象です。放射は電磁波によるもので、反射と同じ意味ではありません。

問6　60Wを2時間使う電力量は何Whか。同じ電力量を7.5Wで使う時間は？
60×2=120Wh
120÷7.5=16時間
問7　重力0.30Nの容器Pが静かに水に浮いている。浮力は？

0.30N。重力と浮力がつり合っています。

問8　空気中でばねばかりが5.00N、全部水中に入れると4.50N。浮力は？
5.00−4.50=0.50N
問9　容器Pを全部沈めると、浮力0.50N、重力0.30N。糸で下から引いて静止させる力は？
0.50−0.30=0.20N（下向き）

上向きの浮力＝下向きの重力＋下向きの糸の力です。

問10　同じ水中で物体が全部沈んだ後、さらに深くすると浮力は大きくなるか。

体積・水の密度が変わらず、底に接しない条件なら、浮力は変わりません。深くなるほど大きくなる水圧と区別します。

問11　磁石のN極をコイルへ近づけると、磁石に向かい合うコイルの面は何極になるか。

N極。近づく変化を妨げるように反発する向きの磁界ができ、誘導電流が流れます。

問12　2つのコイルで、スイッチを入れた瞬間だけ電流が生じ、すぐ0になったのはなぜか。

入れた瞬間は磁界が変化したからです。直流が一定になると磁界が変化せず、誘導電流が続きません。交流なら電流と磁界が時間とともに変化します。
