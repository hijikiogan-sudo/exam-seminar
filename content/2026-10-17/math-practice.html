実践1｜場合分けした面積と、R：S＝5：2

講義の板書をもとに、式・面積条件を明示して再構成した問題

講義はAB＝4cm、AD＝8cmの長方形ABCDを、動く折り目PQで折り返す問題。PはA→B→E、QはA→D→Fへ毎秒1cmで動き、PはEで、QはFで停止する。EはBCの中点、FはDCの中点。Pは8秒で止まり、Qは10秒で止まる。

出発後の時間をx秒（0 ≤ x ≤ 10）とする。Rは折り返した図形全体の面積、Sは元の長方形との重なり部分の面積（cm²）。RはSを含む。Rを折る前の位置へ戻して考えると、RとSを合わせた面積が求めやすい。Sと面積の和T＝R＋Sが次の表で与えられるとき、R：S＝5：2となるxをすべて求めよう。

範囲ST＝R＋S
0 ≤ x ≤ 4x²/2x²
4 ≤ x ≤ 884x
8 ≤ x ≤ 10−2x＋2432

元図をそのまま再現した問題文ではない。講義の3場面と板書の式を、単独でも条件不足なく解ける形に整理している。

補足：Rの面積関数も確かめよう

表からR＝T−S。3区間で順に、R＝x²/2、R＝4x−8、R＝2x＋8となる。Rの面積をyと置くなら、この式をそれぞれのxの範囲とセットで書く。

着眼点

Rを別々に求める前に、Sが全体Tの2/7であると置く。3区間すべてで調べ、区間外の値を取り除く。

途中式1：0 < x ≤ 4の場合

R＝x²−x²/2＝x²/2＝S。したがってR：S＝1：1であり、5：2にはならない。x＝0ではR＝S＝0となり、比が定義できないため最初から除く。

途中式2：4 ≤ x ≤ 8の場合

S＝T×2/7より、

8＝4x×2/7
56＝8x
x＝7

7は4 ≤ x ≤ 8を満たすので採用する。

途中式3：8 ≤ x ≤ 10の場合
−2x＋24＝32×2/7
−14x＋168＝64
14x＝104
x＝52/7

52/7 < 8なので、この区間では不適。採用しない。

解答：x＝7
検算：T＝28、S＝8、R＝20。20：8＝5：2で条件に合う。

別の確かめ方

最後の区間ではT＝32だから、必要なSは64/7（約9.14）。しかしこの区間のSは4～8なので不可能。方程式を解く前にも除ける。

失点しやすい所

  • S＝全体×2/5としてしまう。全体に対しては2/7。
  • 中央の区間だけ調べ、ほかの可能性を説明しない。
  • x＝52/7も答えに残す。各式の成立範囲を必ず確認する。

類題1｜S＝6となるxをすべて求める

上の面積モデルを使う独自の補足問題

同じSの式でS＝6になるxを求めよう。先にグラフを思い浮かべ、答えが何個ありそうか考える。

解答・途中式を見る
  1. 0 ≤ x ≤ 4：x²/2＝6からx²＝12。x ≥ 0なのでx＝2√3。0～4に入る。
  2. 4 ≤ x ≤ 8：Sは8なので解なし。
  3. 8 ≤ x ≤ 10：−2x＋24＝6からx＝9。範囲内。

解答：x＝2√3、9。二次方程式で−2√3が出ても、xの条件で除く。

実践2｜重なっていない面積が、重なりの8倍

講義の板書の数値・式をもとに再構成した問題

面積18cm²と32cm²の2枚の三角形を重ねる。共通部分は、直角をはさむ2辺がともにx cmの直角二等辺三角形。重なっていない部分の面積の合計が、共通部分の面積の8倍になるとき、xを求めよう。xは正で、図が成り立つ範囲を0 < x ≤ 6とする。

着眼点：面積を色分けして数える

共通部分をT、片方にだけ含まれる部分の合計をUとする。2枚の三角形の面積を足すと、共通部分を2回数えることに注意。

途中式と解答を見る
T＝x²/2、U＝8T
18＋32＝U＋2T＝10T
50＝10×x²/2
5x²＝50
x²＝10
x＝±√10

x > 0より、x＝√10 cm。√10は約3.16なので0 < x ≤ 6も満たす。

解の吟味と検算

T＝10/2＝5cm²。U＝50−2×5＝40cm²。40＝8×5なので条件に合う。重ねて見える領域の面積は50−5＝45cm²で、U＝40とは違う。

失点しやすい所

  • 18＋32から共通部分を1回だけ引いてUにしてしまう。
  • 「8倍だから全体は9倍」とする。2枚の面積の和なら10倍。
  • 長さなのに−√10も答えに残す。

類題2｜「何倍」が変わっても同じ考え方

独自の補足問題

面積8cm²と18cm²の2枚を重ね、共通部分が直角二等辺三角形（直角をはさむ2辺がx cm、0 < x ≤ 4）になった。重なっていない部分の合計が共通部分の11倍のとき、xを求めよう。

解答・途中式を見る
8＋18＝(11＋2)T
26＝13T → T＝2
x²/2＝2 → x²＝4
x＝2

解答：2cm。検算すると、重ならない部分は26−2×2＝22cm²で、共通部分2cm²の11倍。
