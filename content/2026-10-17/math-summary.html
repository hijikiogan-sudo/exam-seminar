重なりの面積は、形が変わる所で場合分け

一つの図だけで最後まで考えない。講義は長方形を動く折り目PQで折り返す問題。移動に伴い「三角形の面積が増える → 面積が一定 → 三角形の面積が減る」という3つの区間に分けた。

解く手がかりとして、先に講義でSとした重なり部分の面積を整理する。出発後の時間をx秒、Sの面積をS cm²とする。点PはA→B→E、点QはA→D→Fへ進み、それぞれE・Fで停止する。点P・Qが毎秒1cmで動くので、停止する前はx秒でx cm進む。板書では次の関係を確認できる。

xの範囲Sの式グラフ
0 ≤ x ≤ 4S＝x²/2放物線の一部。直角二等辺三角形の面積。
4 ≤ x ≤ 8S＝8水平な直線。底辺4、高さ4の三角形。
8 ≤ x ≤ 10S＝4(12−x)/2＝−2x＋24右下がりの直線。
元の動き・点名の細部は講義の問題用紙と照合しよう。このノートの実践版では、板書で確認できた式と必要な面積条件を明示して、解き直せる問題に再構成している。
確認1：x＝4とx＝8で、前後の式はつながる？

x＝4では4²/2＝8。x＝8では−2×8＋24＝8。どちらも一定区間のS＝8と一致する。境目で式がつながるかは、場合分けの検算になる。

補足：Rの面積yも式にする

R＋Sになる面積は、最初はx²、中央は4x、最後は長方形全体の32。そこからSを引くと、Rの面積yも計算できる。

範囲Rの面積 y
0 ≤ x ≤ 4y＝x²−x²/2＝x²/2
4 ≤ x ≤ 8y＝4x−8
8 ≤ x ≤ 10y＝32−(−2x＋24)＝2x＋8

x＝4ではy＝8、x＝8ではy＝24。境目で前後の値が一致する。SのグラフとRのグラフを取り違えないよう、縦軸に何の面積か書こう。

確認：x＝9秒のとき、RとSの面積は？

S＝−2×9＋24＝6cm²。Rの面積y＝2×9＋8＝26cm²。合計32cm²で長方形全体の面積に一致する。

面積の比は「全体の何分のいくつ」へ

R：S＝5：2 なら、S＝(R＋S)×2/7

SをRの2/5として使う方法もあるが、R＋Sの面積が簡単なら、全体の2/7にする方が短い。分母は5＋2＝7。

講義では中央の区間でR＋S＝4x、S＝8を使い、4x×2/7＝8からx＝7を求めた。出てきた値が4 ≤ x ≤ 8に入ることまで確かめる。

確認2：別の区間の式からx＝52/7が出た。8 ≤ x ≤ 10の解にできる？

できない。52/7は約7.43で8未満。計算が合っていても、その式を立てた区間の条件に合わなければ除く。

「重ならない部分」は、重なりを2回引く

2枚の図形の面積を足すと、共通部分は2回数えられる。共通部分をT、2枚のうち片方にだけ含まれる部分の合計をUとする。

2枚の面積の合計 ＝ U ＋ 2T
U＝kT なら、2枚の面積の合計＝(k＋2)T

講義の例では18＋32＝50。「重ならない部分が重なる部分の8倍」なので、50＝(8＋2)T＝10T。T＝x²/2を代入すれば5x²＝50となる。

確認3：「重ならない部分が重なる部分の8倍」なら、面積の合計は9倍？10倍？

10倍。8倍の部分と、重なり2回分を合わせるため。紙全体の和と、2枚を重ねて見える領域の面積を混同しない。

①どこで形が変わるか　②全体は何の面積か　③答えを戻す範囲はどこか。実践版で途中式と類題まで確認しよう。
