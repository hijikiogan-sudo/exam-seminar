「第3回 学習の診断」に向けた対策。板書では2次方程式、記述・証明、動く図形、図形・回転体が整理され、後半は円錐や回転体の面積・体積を図から読み取る練習が中心でした。

2次方程式
因数分解・平方根・解の公式を使い分ける。
記述・証明
式変形だけでなく「なぜそう言えるか」を文章でつなぐ。
円錐

講義内容を順に整理

1. 2次方程式は「解き方の選択」が勝負

2次方程式は形を見て最短の方法を選びます。

形優先する方法
x² = a平方根
x² + bx + c = 0 が分解できる因数分解
分解しにくい一般形解の公式
途中で移項や符号を誤ると最後までずれるので、まず =0 の形を整えるのが基本。

2. 記述・証明は「根拠を1行ずつ」

板書には整数に関する説明、2次方程式、証明が記述分野として挙げられていました。答案では計算結果だけでなく、置き方 → 式 → 変形 → 結論の順に書きます。

3. 円錐の側面積

円錐の側面積 = π × 底面の半径 r × 母線 l

つまり πrl。展開図の側面は扇形なので、弧長は底面の円周 2πr と一致します。

扇形の弧長 / 母線を半径とする円周 = 中心角 / 360°

4. 回転体は「何が半径になるか」を図示

平面図形を直線のまわりに回転すると、円柱・円錐・それらの組合せができます。回転軸から各点までの距離が、できる立体の半径になります。

5. 複合立体は「足す・引く」に分解

講義後半では、複数の三角形や四角形を回転させた図を使って体積を考えていました。複雑に見える立体も、円柱・円錐に分解し、必要に応じて差を取ります。

円柱：V = πr²h　　円錐：V = ⅓πr²h

なぜこの考え方が有効なのか

1
公式の丸暗記だけでは図形に対応できない
どの長さが半径・高さ・母線なのかを図から決める必要があります。
2
回転体は断面で考えると単純になる
立体を一度平面に戻し、回転軸からの距離を見ると構造が分かります。
3
記述は途中点を取れる
式や根拠を残せば、最終計算を誤っても考え方に点が付く可能性があります。

入試での問われ方

出題パターン
  • 2次方程式の計算・文章題。
  • 整数の性質を文字式で説明する記述。
  • 図形の合同・相似などの証明。
  • 円錐の展開図から中心角・側面積を求める。
  • 平面図形を回転させた立体の体積・表面積。
  • 動く点・動く図形と面積の変化。

本番の図形チェック

  1. 回転軸を太く書く。
  2. 軸からの距離＝半径を図に書き込む。
  3. 高さ・母線を区別する。
  4. 立体を円柱・円錐などに分解する。
  5. 最後に π と 1/3 の付け忘れを確認する。

つまずきやすい点

母線と高さを混同
円錐の側面積は母線、体積は垂直な高さ。
回転軸からの距離を見ない
半径は図の「横の長さ」とは限らない。
円錐の1/3を忘れる
体積は ⅓πr²h。
記述で結論だけを書く
根拠となる式・性質を途中に残す。

確認問題

Q1. 円錐の側面積を r, l で表すと？

πrl です。

Q2. 円錐の体積は？

⅓πr²h です。

Q3. 回転体の半径はどこから決める？

回転軸から図形上の点までの垂直距離から決めます。

Q4. 記述答案で最低限残すべき流れは？

置き方 → 式 → 変形・根拠 → 結論です。
