この回の要点

テーマは不定詞①。単なる「to＋動詞の原形」の暗記ではなく、文のどこに置かれ、何を説明しているかを見て判断するのが中心です。特に、It is … to dotoo … to do… enough to doの変換が重要です。

It is … to do
「〜することは…だ」。形式主語 it を使う型。
too … to do
「…すぎて〜できない」。否定の意味を含む。
… enough to do
「〜するのに十分…だ／〜できるほど…だ」。
書き換え
so … that S cannot/can … との対応を理解する。

講義内容を順に整理

1. 不定詞はまず「to＋動詞の原形」を一まとまりで見る

英文中の to + 動詞の原形 を見つけたら、前後との関係を確認します。不定詞だけを訳すのではなく、主語・動詞・形容詞との結びつきを見ます。

2. It is + 形容詞 + to do

It is + 形容詞 + to do …
＝「…することは〜だ」

長い主語になる to do を後ろに置き、文頭の It を形式主語にする形です。

3. too + 形容詞 + to do

He is too poor to buy this car.
＝ 彼は貧しすぎて、この車を買えない。

講義ではこの文を使い、too … to には「できない」という否定の意味が含まれることを確認していました。

too + 形容詞 + to do
⇔ so + 形容詞 + that + S + cannot + 動詞

例：He is too poor to buy this car. ⇔ He is so poor that he cannot buy this car.

4. 形容詞 + enough + to do

He is rich enough to buy this car.
＝ 彼はその車を買えるほど十分裕福だ。

enough は形容詞の後ろに置かれる点が重要です。

形容詞 + enough + to do
⇔ so + 形容詞 + that + S + can + 動詞

5. 「できる／できない」を軸に変換する

型意味that節への変換
too … to do…すぎて〜できないso … that S cannot …
… enough to do〜できるほど十分…so … that S can …

なぜこの整理が有効なのか

1
語順問題に強くなる
enough の位置、to の後ろの動詞原形などを型として再現できます。
2
書き換え問題を意味で処理できる
too＝cannot、enough＝can という対応を押さえると、丸暗記が減ります。
3
長文中でも機能を見抜きやすい
不定詞を一まとまりとして見れば、文の骨格を崩さず読めます。

入試での問われ方

出題パターン
  • 並べ替え：too / enough / to の位置。
  • 書き換え：too … to と so … that … cannot。
  • 書き換え：… enough to と so … that … can。
  • 和訳：不定詞が何を説明しているか。
  • 空所補充：to の後ろを動詞原形にする。

本番チェック

  1. to の後ろは動詞原形か。
  2. too の文は「できない」の意味になっているか。
  3. enough は形容詞の後ろにあるか。
  4. that節に直したとき、can / cannot が正しいか。

つまずきやすい点

too を「とても」と訳す
too … to では「…すぎて〜できない」。
enough の位置
enough rich ではなく rich enough。
to の後ろを過去形にする
原則として動詞原形。
書き換えで肯定・否定を逆にする
too→cannot、enough→can を軸に確認。

確認問題

Q1. He is too tired to walk. を that節で言い換えると？

He is so tired that he cannot walk.

Q2. She is old enough to drive. の enough はなぜ old の後ろ？

形容詞 + enough + to do という語順だからです。

Q3. too … to と enough … to の大きな意味の違いは？

too … to は「できない」、enough … to は「できる」方向の意味になります。
